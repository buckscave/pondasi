pondasi — pintasan keyboard

v
Split vertikal (kiri-kanan). Pada grand-parent: buat section.baris + 2 kolom-6. Pada parent/sub-baris: tambah kolom-baru atau split child aktif.
h
Split horisontal (atas-bawah). Pada grand-parent: tambah section.baris. Pada parent: tambah sibling section.baris. Pada sub-parent: tambah sub-baris child.
<N> + v / h
Motion split jadi N region proporsional. Contoh: 6v → 6 kolom, 3v → 3 kolom, 5v → 5 kolom-lima (sistem 10), 7h → 7 section. N genap (2, 3, 4, 6, 12) pakai sistem 12 kolom; N ganjil (5, 7, 8, 9, 10, 11) pakai sistem 10 (kolom-lima, kolom-tujuh, dll).
Alt + v
Split vertikal pada kolom. Kolom dijadikan sub-parent (.kolom-N.sub-baris) + 2 kolom-N/2 di dalamnya.
Alt + h
Split horisontal pada kolom. Kolom jadi sub-parent + 2 sub-baris (block stack).
← ↑ → ↓
Navigasi region aktif (geometri — cari leaf terdekat di arah panah).
Alt + ←/→
Resize kolom (step: 1 kolom). Sibling auto-balance (total tetap). Kolom ganjil tidak bisa di-resize.
Alt + ↑/↓
Resize tinggi baris (step: 1rem / 16px).
Ctrl + ←/↑/→/↓
Swap posisi dengan region di arah panah.
Shift + ←/↑/→/↓
Multi-select region di arah panah. Setelah multi-select: Backspace hapus semua terpilih, Ctrl+arrow pindah semua terpilih bersamaan, j gabung (merge/join) region adjacent.
Backspace
Hapus region aktif (atau semua terpilih). Sibling menyesuaikan mengisi kekosongan. Untuk kolom ganjil: konversi otomatis ke sistem 12 (mis. kolom-lima hapus 1 → 4 kolom-3).
j
Gabung region terpilih (untuk kolom adjacent: jumlahkan kolom-N). Tidak bisa untuk kolom ganjil.
l
Kunci/buka kunci region aktif. Region terkunci tidak bisa di-split (v/h), dihapus (Backspace), digabung (j), atau dipindah. Visual: border kuning dashed + ikon gembok. Lock hanya editor state, tidak diekspor ke HTML.
w
Buka/tutup panel properti region (inspector permanen). Panel region selalu tampil secara default — (w) bisa hide/show kalau perlu ruang canvas penuh.
u / Ctrl+Z
Undo operasi terakhir.
r / Ctrl+Y / Ctrl+Shift+Z
Redo operasi yang di-undo.
Enter
Masuk mode edit pada region terpilih. Tekan Esc atau klik di luar region untuk keluar (konten otomatis tersimpan).
?
Tampilkan/sembunyikan bantuan ini.
D (di luar mode edit)
Buka panel berkas / dokumen (buka, buat, hapus).
T (di luar mode edit)
Buka panel template wireframe.
S (di luar mode edit)
Simpan dokumen.
E (di luar mode edit)
Buka panel ekspor (HTML, CSS, checklist).
, (di luar mode edit)
Buka panel pengaturan (preferensi).
Esc
Bersihkan seleksi / tutup modal / keluar mode edit.

Di mode edit (block)

i
Buka/tutup/switch dropdown Isi (paragraf, heading, daftar, gambar, dll). Tekan i sekali: buka. Tekan lagi: tutup. Kalau dropdown Komponen terbuka: switch ke Isi.
k
Buka/tutup/switch dropdown Komponen (tombol, kartu, form, navigasi, dll). Sama seperti i tapi untuk komponen.
e
Toggle panel properti region (margin, padding, border, warna, kelas). Kalau dropdown terbuka: tutup dropdown dulu.
↑ / ↓
Navigasi block aktif (single-select).
Shift + ↑/↓
Multi-select block — extend seleksi ke block di atas/bawah. Outline hijau menandai block yang terpilih.
Ctrl + A
Pilih semua block di region.
Shift + klik
Toggle multi-select block individual.
Backspace
Hapus block aktif (atau semua terpilih kalau multi-select).
Ctrl + ↑/↓
Pindah (reorder) block aktif naik/turun. Kalau multi-select: pindah semua bersamaan.
y
Yank (copy) block aktif ke clipboard.
x
Cut block aktif ke clipboard.
p
Paste block dari clipboard setelah block aktif.
Enter
Masuk ke panel properti block (jika sudah pilih block). Fokus pindah ke field pertama.
Double-click block
Aktifkan edit teks inline (contentEditable).
Drag block
Reorder block via mouse — drag ke posisi lain, lepas untuk drop.
